# Sample Gesture Guide

These gestures are simple demo suggestions for collecting a consistent classroom dataset. They are not an official sign-language dictionary.

| Sign | Demo gesture suggestion |
| --- | --- |
| hello | Open palm facing the camera, slight wave. |
| yes | Closed fist, small up-down motion. |
| no | Index and middle finger extended, then close toward thumb. |
| help | One hand open as a base, other hand in a thumbs-up shape above it. |
| water | Three fingers raised near chin or in front of camera. |
| food | Fingers grouped near mouth area. |
| medicine | Middle finger touching palm or a clear medicine-related hand pose. |
| thank_you | Open hand moving away from chin. |
| please | Open palm near chest, circular motion if desired. |
| stop | Open palm facing camera. |
| good | Thumbs-up. |
| bad | Thumbs-down. |
| doctor | Two fingers on opposite wrist, like checking pulse. |
| pain | Point to palm or make a clear hurt/pain pose. |
| toilet | Closed fist with thumb between fingers, held clearly. |
| home | Flat hand near cheek, then near chin, or one consistent home pose. |
| phone | Thumb and little finger extended like a phone near ear. |
| sorry | Fist or open palm near chest, small circular motion if desired. |
| more | Fingertips of both hands touching, or one clear plus/more pose. |
| emergency | Open hand waving sharply, or a clear urgent alert pose. |

For best model performance, keep the gesture style consistent during collection and testing.
